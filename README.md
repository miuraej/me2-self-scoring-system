# ME2 Self-Scoring System

第2種ME、国試、統一模試、その他の試験に対応する自己採点・集計システムです。問題文を表示せず、問題冊子を見ながら回答番号だけを記録します。12問トライアルは `trial-12q-v1` タグに保存されています。

## 起動

ES Modules と JSON 読み込みを使用するため、ローカルHTTPサーバーから開いてください。

```powershell
npm start
```

ブラウザで `http://localhost:8000` を開きます。

## 主な機能

- 公開中の複数試験から試験名で選択
- 第2種ME（60問×2）、国試・統一模試（90問×2）、任意問題数の試験作成
- 1〜5および「未開回答」の入力と自動保存
- 未入力と未開回答の区別
- 提出用CSVの出力
- 正答公開前／公開後の切り替えと自己採点
- 通常正答、複数正解、全員正解、採点除外
- 正答を含まない初期配布データ
- 独立した管理者画面での正答登録と公開済みJSON出力
- 学生CSVの複数読込、検証、学内集計
- 得点・学内平均・全国平均の比較
- 利用開始日時・利用期限の設定
- 4種類の教員用CSV出力

学生の入力・CSVはブラウザ内だけで処理され、外部サーバーには送信されません。

## Web公開

`main` ブランチへの反映時に、GitHub Pagesへ受験者画面だけを公開します。管理者画面、教員集計画面、仕様書、ローカルサーバーは公開物に含めません。受験者画面で採点するため、公開済み正答JSONと学内平均JSONは公開物に含まれます。

## 画面

- `index.html`: 受験者用
- `admin.html`: 管理者用の正答データ作成
- `teacher.html`: 教員用のローカル集計

初期状態には正答、採点方式、問題文、解説を含みません。管理者画面で正答を登録した後、受験者は「採点」ボタンから結果を確認できます。教員用の別端末へは、登録済み正答JSONを出力して渡します。
