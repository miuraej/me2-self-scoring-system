# ME2自己採点・集計システム 全体仕様書

Version 0.4  
作成日：2026年9月5日

## 1. 目的

第2種ME技術実力検定、国家試験、統一模試および任意形式の試験について、受験者が問題冊子を見ながら回答番号を記録し、公開済み正答に基づいて自己採点できるWebシステムを提供する。

問題文、選択肢本文および解説は作成・表示しない。受験者の回答と任意入力の個人情報はブラウザ内に保存し、外部サーバーやGitHubへ送信しない。提出・集計が必要な場合は、受験者が出力したCSVを管理者が別経路で収集し、ローカルPC上で集計する。

## 2. システム構成

### 2.1 受験者用Web画面

- GitHub Pagesで公開する。
- 公開中の試験を試験名から選択できる。
- URLの試験IDから対象試験を直接開ける。
- 回答入力、自動保存、CSV出力、自己採点、結果表示を行う。
- 管理者画面および教員集計画面は公開物へ含めない。

### 2.2 管理者用ローカル画面

- 管理者PCのローカルHTTPサーバー上で利用する。
- 試験設定、分野、正答、採点方式、平均得点率、公開状態および利用期限を管理する。
- 正答データの登録、変更、未登録化、CSV入出力、JSON出力を行う。

### 2.3 教員用ローカル集計画面

- 受験者から回収した複数CSVをローカルで読み込む。
- データ検証、採点、集計、分析、CSV出力を行う。
- 回答CSVおよび個人情報をGitHubや外部サービスへ送信しない。

## 3. 対応する試験種別

| 試験種別 | 午前 | 午後 | 分野設定 |
|---|---:|---:|---|
| 第2種ME | 60問 | 60問 | 午前・午後それぞれ6分野を10問ずつ初期設定 |
| 国試 | 90問 | 90問 | 問題ごとに設定。分野別問題数は可変 |
| 統一模試 | 90問 | 90問 | 国試と同様。分野別問題数は可変 |
| その他 | 任意 | 任意 | 問題ごとに設定 |

### 3.1 第2種MEの分野初期値

午前・午後の双方に次の初期値を設定する。管理者による変更を可能とする。

| 問題番号 | 分野 |
|---|---|
| 問1～10 | 基礎医学 |
| 問11～20 | 基礎工学 |
| 問21～30 | 基礎ME |
| 問31～40 | 原理構造 |
| 問41～50 | 操作運用 |
| 問51～60 | 保守安全 |

分野別結果は午前・午後を合算する。通常は各分野20問を分母とし、採点除外があればその問題数を分母から除く。

## 4. 試験データ

試験ごとに一意の試験IDを付与し、次の情報を保持する。

- 試験ID
- 試験名
- 試験種別
- 実施日または年度
- データ形式バージョン
- 公開バージョン
- 午前・午後の問題数
- 選択肢数
- 分野一覧
- 試験の公開状態
- 正答の公開状態
- 利用開始日時
- 利用期限
- 更新日時

問題ごとに次の情報を保持する。

- 問題ID
- 試験ID
- 午前・午後の区分
- 問題番号
- 分野
- 選択肢数
- 配点
- 採点方式
- 正答番号

公開前の基本試験データには正答を含めない。正答は公開済み正答データとして分離する。

## 5. 回答入力

- 各問題で1～選択肢数、または「未開回答」を選択できる。
- 初期状態はすべて未入力とする。
- 未入力と「未開回答」を区別する。
- 全体および午前・午後ごとの入力済み数を表示する。
- 未入力数、「未開回答」数、未入力問題番号を表示する。
- 回答は1問ごとにLocalStorageへ保存する。
- 保存領域は試験IDごとに分離する。
- 再読み込み後も回答を復元する。
- リセット時は確認を表示する。

## 6. 提出用CSV

受験者1名につき1ファイルを出力する。最低限、次の列を含む。

- 試験ID
- データ形式バージョン
- 学籍番号（任意）
- 氏名（任意）
- 生成日時
- 試験データバージョン
- 午前・午後の全回答

回答値は次のとおりとする。

| 値 | 意味 |
|---|---|
| `1`～選択肢数 | 選択した回答 |
| `U` | 未開回答 |
| 空欄 | 未入力 |

未入力があってもCSV出力は可能とするが、出力前に警告する。

## 7. 正答管理

### 7.1 採点方式

| 値 | 表示名 | 動作 |
|---|---|---|
| `normal` | 通常正答 | 指定した1つの番号を正答とする |
| `multiple` | 複数正答候補 | 指定した複数番号のいずれかを正答とする |
| `all_correct` | 全員正解 | 回答内容にかかわらず正解とする |
| `excluded` | 採点除外 | 得点と採点対象問題数から除外する |

全員正解および採点除外では、正答番号を空欄にし、入力を無効化する。

### 7.2 正答番号の入力補助

次期改定で次を自動的に標準化する。

- 全角数字を半角数字へ変換
- 全角カンマおよび読点を半角カンマへ変換
- 前後の空白を除去
- 重複番号を整理
- 選択肢数の範囲外をエラー表示

### 7.3 登録状態

- 「検証して登録」で正答を登録または更新する。
- 「正答を未登録に戻す」で公開済み正答の登録を解除する。
- 正答未登録時に受験者が採点すると「まだ正答が登録されていません」と表示する。
- 正答登録解除後も、受験者の保存済み回答は削除しない。

## 8. 自己採点

- 管理者が登録した最新の公開済み正答を使用する。
- 回答済みの試験は、正答変更後に再採点できる。
- 通常正答、複数正答候補、全員正解、採点除外を反映する。
- 午前、午後、総合および分野別に集計する。
- 分野別得点は午前・午後を合算する。

本人の結果は次の形式で表示する。

`正答数 / 採点対象問題数（得点率%）`

学内平均と全国平均は得点率（%）のみを表示し、未登録と0%を区別する。結果表の本人列名は「得点」とする。

## 9. 試験選択と公開状態

- 公開中の複数試験を受験者画面の一覧へ表示する。
- 一覧には試験名を使用する。
- URLクエリに試験IDを指定して直接表示できる。
- 試験の公開状態と正答の公開状態を分離する。
- 試験公開中・正答未登録の場合も、回答入力とCSV出力は利用できる。
- 正答登録済みの場合だけ自己採点できる。
- 試験を切り替えても、各試験の保存済み回答を保持する。

## 10. 利用期限

試験ごとに日本時間で利用開始日時と利用期限を設定できる。

- 利用開始日時は任意とする。
- 利用期限は任意とし、未設定なら期限なしとする。
- 開始前は「この試験はまだ利用できません」と表示する。
- 利用期間中は回答入力、CSV出力および正答登録済みの場合の採点を利用できる。
- 期限後は採点を停止し、「この試験の採点期限は終了しました」と表示する。
- 期限後も保存済み回答を自動削除しない。
- 管理者は期限を延長または解除できる。

本機能は画面上の利用制限であり、公開GitHubリポジトリ上の正答JSONを秘匿するセキュリティ機能ではない。

## 11. 教員集計

- 複数の回答CSVを一括読み込みする。
- 試験ID、形式バージョン、必要列、回答範囲を検証する。
- 未入力と未開回答を区別する。
- 午前、午後、総合、分野別得点を算出する。
- 学内平均得点率を算出する。
- 問題別正答率、選択肢分布、未回答数、未入力数を算出する。
- 集計結果をCSVとして出力する。

最低限、次のファイルを出力する。

- `all_answers.csv`
- `score_results.csv`
- `question_analysis.csv`
- `category_analysis.csv`

## 12. 公開・運用

### 12.1 GitHub Pages公開物

- 受験者画面
- 公開中試験の基本データ
- 公開済み正答データ
- 公開済み学内平均・全国平均データ

### 12.2 非公開の運用データ

- 受験者の回答CSV
- 学籍番号および氏名
- 実際の集計作業ファイル

管理者画面と教員集計画面はリポジトリ内に保存してもよいが、GitHub Pagesの公開成果物には含めない。

正答を機密情報として扱う必要が生じた場合は、公開GitHub Pages方式から採点APIを持つサーバー方式へ移行する。

## 13. 検証とバージョン管理

- 公開データへの正答混入を検査する。
- 正答データと試験IDの整合性を検査する。
- 選択肢数、採点方式、正答番号を検査する。
- CSVの必須列、重複列、不正回答を検査する。
- 問題数と午前・午後の構成を検査する。
- GitHub Actions成功後に公開画面を確認する。

12問トライアル版はGitタグ `trial-12q-v1` として保存済みである。次期版はこのタグを変更せず、別コミットとして開発する。

## 15. 次期版の完了条件

- 4種類の試験種別を選択できる。
- 試験種別に応じた午前・午後の問題数が初期設定される。
- 第2種MEでは6分野が各10問ずつ初期入力される。
- 国試と統一模試では問題ごとに可変の分野を設定できる。
- 複数試験を登録し、受験者が試験名から選択できる。
- 試験IDを含むURLから直接アクセスできる。
- 試験ごとに回答が保存される。
- 利用開始日時と利用期限が機能する。
- 全角の正答番号入力を自動標準化できる。
- 正答登録、変更、未登録化が試験ごとに独立して動作する。
- 本番問題数でも管理者画面と受験者画面が実用的に操作できる。
