# 第2種ME技術実力検定試験 自己採点・集計システム仕様書

> この文書はVer.0.3時点の記録です。最新仕様は [ME2自己採点・集計システム仕様書_Ver0.4.md](./ME2自己採点・集計システム仕様書_Ver0.4.md) を参照してください。

Version 0.3 / 2026-09-05

## 1. 目的

第2種ME技術実力検定試験（ME2種）の受験者が、試験終了後に自身の解答を入力・保存し、提出用CSVを出力できるWebアプリを構築する。正答公開後は保存済み解答を再入力せずに自己採点する。

提出CSVはLMS（melly）で収集し、教員PC上でスタンドアロン集計する。学生の個人情報・解答は外部サーバー、外部API、生成AIへ送信しない。

Ver.1はME2種専用とするが、問題数、選択肢数、分野、採点方式をデータで定義し、他試験へ拡張可能にする。

## 2. システム構成

### 2.1 受験者用Webアプリ

試験選択、解答入力、自動保存、CSV出力、正答取得、自己採点、結果表示を行う。受験者情報の入力は任意とし、入力データはブラウザ内にだけ保存する。

### 2.2 公開用試験データ管理

試験ID、試験名、実施日、区分、問題数、選択肢数、分野、正答、採点方式、全国平均、データバージョン、更新日時を管理する。公開データに個人情報を含めない。

### 2.3 教員用スタンドアロン集計

学生CSVの一括読込、検証、採点、学内集計、問題・分野分析、結果CSV出力を行う。主要機能はオフラインで動作する。

## 3. 共通データ形式

Question Training Platformとの共通化を前提とする。

### 3.1 `exam.json`

```json
{
  "examId": "ME2_47",
  "examName": "第47回 第2種ME技術実力検定試験",
  "examType": "ME2",
  "version": "1.0",
  "formatVersion": "1",
  "answerStatus": "unpublished",
  "sections": [
    { "id": "am", "name": "午前", "questionCount": 60 },
    { "id": "pm", "name": "午後", "questionCount": 60 }
  ]
}
```

### 3.2 `questions.json`

```json
{
  "id": "me2-2026-47-am-01",
  "examId": "ME2_47",
  "section": "am",
  "number": 1,
  "category": "基礎医学",
  "choiceCount": 5,
  "correctAnswers": [3],
  "scoring": "normal",
  "text": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4", "選択肢5"],
  "explanation": "解説"
}
```

Training Platformは問題文・選択肢・解説まで利用し、自己採点アプリは主に問題ID、区分、番号、分野、選択肢数、正答、採点方式を利用する。

### 3.3 採点方式

| 値 | 意味 |
|---|---|
| `normal` | 通常正答 |
| `multiple` | `correctAnswers` のいずれかを正答とする |
| `all_correct` | 全員正解 |
| `excluded` | 採点対象・満点から除外 |

## 4. ME2種 Ver.1

- 午前60問、午後60問、合計120問
- 原則1問1点、選択肢は1〜5
- 問題数等はプログラムに固定せず試験データから読む
- 分野は「基礎医学」「基礎工学」「基礎ME」「原理構造」「操作運用」「保守安全」の6分野（各20点）

## 5. 解答入力と保存

- 各問題で1〜5または「本番未回答」を選択できる。
- 初期状態はすべて「選択なし」とする。
- 選択なし、1〜5、本番未回答を区別する。
- 入力済み数、未入力数、本番未回答数、未入力問題番号を表示する。
- 1問入力するごとにLocalStorageへ保存し、再読み込み後に復元する。
- リセット時は確認を表示し、試験公開データは削除しない。

## 6. 学生提出用CSV

1名1ファイルとし、基本形式を次のとおりとする。

```csv
exam_id,format_version,student_id,student_name,AM01,AM02,...,PM60
ME2_47,1,,,2,4,...,5
```

| CSV値 | 意味 |
|---|---|
| `1`〜`5` | 回答 |
| `U` | 本番未回答 |
| 空欄 | アプリ上で未入力 |

未入力がある場合は警告するが、CSV出力は禁止しない。

## 7. 正答公開と自己採点

- 正答未公開時も解答入力、保存、CSV出力を利用できる。
- 正答公開後、保存済み解答を最新公開データで採点する。
- 正答変更、複数正解、全員正解、採点除外の変更後に再採点する。
- 総合点と分野別本人得点を表示する。
- 全国平均登録後は本人・学内平均・全国平均を表またはチャートで比較する。

## 8. 教員集計

複数CSVをまとめて読み込み、試験ID、形式バージョン、解答数、不正値、未回答、未入力を検証する。正常データから総合・分野別得点、学内平均、問題別正答率、選択肢分布を算出する。

最低限、次を出力する。

- `all_answers.csv`: 全学生の生解答
- `score_results.csv`: 総合・分野別得点
- `question_analysis.csv`: 正答率、選択肢分布、未回答数、未入力数
- `category_analysis.csv`: 分野別学内平均・全国平均

## 9. 6問トライアル

本番版の前に、6分野から各1問ずつ、計6問のトライアルを実装する。各問題は5択で、本番未回答も選べる。

| 問題 | 分野 |
|---|---|
| 問1 | 基礎医学 |
| 問2 | 基礎工学 |
| 問3 | 基礎ME |
| 問4 | 原理構造 |
| 問5 | 操作運用 |
| 問6 | 保守安全 |

### 9.1 実証手順

1. 正答未公開で解答入力、自動保存、再読込復元、CSV出力を確認する。
2. CSVで1〜5、`U`、空欄、試験IDが正しく保持されることを確認する。
3. 正答を公開し、保存済み解答が自動採点されることを確認する。
4. 通常正答から複数正解への変更、別問題の採点除外への変更で再計算を確認する。
5. 複数人分のCSVから学内平均、問題別正答率、分野別結果を算出する。
6. 仮の全国平均を登録し、本人・学内平均・全国平均を比較する。

### 9.2 合格条件

- 解答入力、未入力／未回答の区別、LocalStorage保存
- CSV生成・一括読込・検証
- 正答未登録、正答登録・変更、複数正解、全員正解、採点除外
- 自己採点、学内平均、全国平均、個人結果、チャート
- 学生CSVを外部へ送信しない

以上が正常動作した後、本番120問版へ拡張する。
