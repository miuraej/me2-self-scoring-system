# 次期改定メモ

対象仕様：Ver.0.4  
作成日：2026年9月5日

## 今回決定した内容

1. 12問トライアルはGitタグ `trial-12q-v1` として保持する。
2. 次期版では複数試験へ対応する。
3. 試験種別は「第2種ME」「国試」「統一模試」「その他」の4種類とする。
4. 第2種MEは午前60問、午後60問とする。
5. 第2種MEは午前・午後それぞれ6分野を10問ずつ初期入力する。
6. 国試と統一模試は午前90問、午後90問とする。
7. 国試と統一模試の分野別問題数は固定しない。
8. その他は午前・午後の問題数を任意設定とする。
9. 受験者は公開中の試験名から試験を選択する。
10. 試験ID付きURLによる直接表示へ対応する。
11. 試験の公開と正答の公開を別々に管理する。
12. 利用開始日時と利用期限を日本時間で設定する。
13. 期限は当面、画面上の利用制限として実装する。
14. 正答番号の全角数字、全角カンマ、読点を自動的に標準化する。
15. 受験者画面だけをGitHub Pagesで公開する。
16. 管理者画面と集計画面はローカルPCで使用する。
17. 回答CSVと個人情報はGitHubへ保存しない。

## 実装順序案

1. 複数試験を表すデータ構造と試験一覧を作成する。
2. 試験種別ごとの初期値生成処理を実装する。
3. 管理者画面に試験作成・選択・編集機能を追加する。
4. 正答番号の全角入力標準化を実装する。
5. 正答・平均値・期限を試験単位で登録できるようにする。
6. 受験者画面に試験選択とURL直接指定を追加する。
7. 利用開始前、期限内、期限後の表示制御を実装する。
8. GitHub Pagesの公開処理から12問試験IDの固定指定をなくす。
9. ローカル集計を可変問題数・複数試験へ対応させる。
10. 第2種ME120問、国試・統一模試180問で動作確認する。

## 実装上の注意

- 問題文、選択肢本文、解説は扱わない。
- 問題数や試験IDをプログラムへ直接固定しない。
- 採点除外は得点だけでなく分母からも除く。
- 未登録、0点、0%を区別する。
- 全員正解と採点除外では正答番号を持たせない。
- 公開済み正答を未登録へ戻した場合、受験者の保存済み回答は残す。
- 利用期限は正答データを秘匿する機能ではないことを画面または運用資料で明示する。
- 大量問題の編集ではCSV一括入力を中心とし、管理画面での個別修正も可能にする。
- 試験ごとに公開バージョンと更新日時を残す。

## 今後確認する項目

- 国試・統一模試で使用する正式な分野名一覧
- 「その他」で午前または午後の片方だけを使用する場合の扱い
- 利用期限後に回答入力とCSV出力も停止するか、採点だけを停止するか
- 試験一覧に過去試験をいつまで表示するか
- 公開済み試験の並び順
- 管理者がGitHubへ反映する操作をどこまで自動化するか
